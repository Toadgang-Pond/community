# Security policy

Please **do not disclose security vulnerabilities or sensitive information in public issues, discussions, or pull requests**.

Use the affected project's GitHub **private vulnerability reporting** channel where available. Until a private reporting path is confirmed, do not send secrets or exploit details through public channels.

A dedicated security contact and response policy will be published before any public software binaries are released.

This repository collects community feedback; it is not the endpoint for production incident handling.
