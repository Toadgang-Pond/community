# 🐸 Toadgang Pond Community

**Built by Toadgang. Open to everyone.**

This is the public place for suggestions, constructive discussion, user feedback, and contributions to Toadgang Pond projects.

## Participate

- [Request a feature](https://github.com/Toadgang-Pond/community/issues/new?template=feature_request.yml)
- [Report a non-sensitive bug](https://github.com/Toadgang-Pond/community/issues/new?template=bug_report.yml)
- Read [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Find approved software at [Toadgang releases](https://github.com/Toadgang-Pond/releases).

## Boundaries

This community space is not a system-administration channel. Please never include passwords, access tokens, seed phrases, recovery keys, private logs, or personal information in issues.

**Security vulnerability?** Do not file it as a public bug. Read [SECURITY.md](SECURITY.md).

Contributors are welcome; publication, permissions, and releases remain subject to project owners' human approval.
