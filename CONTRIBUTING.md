# Contributing to Toadgang Pond

Thank you for helping the pond grow.

## Ways to contribute

- Propose focused improvements with a clear reason and expected user benefit.
- Submit reproducible, **non-sensitive** bug reports.
- Help improve public documentation and accessibility.
- For code contributions, follow the instructions in the specific project's source repository.

## Contributions are reviewed

Keep changes small and well scoped. Explain tests and compatibility impact. Never bundle secrets, actual user data, third-party code without permissions, or unapproved dependencies.

We do not merge unreviewed changes or bypass project CI and security gates. Participation does not grant direct publishing or production privileges.

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).
